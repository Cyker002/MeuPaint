# Meu Paint - Simulador de Desenho

Este repositório contém um **programa de desenho** interativo, inspirado nas funcionalidades do clássico MS Paint. O projeto foi desenvolvido em **Java** e utiliza uma engine gráfica fornecida em contexto acadêmico para capturar os cliques do mouse e renderizar os traços na tela.

## 🎨 Funcionalidades
* Desenho livre utilizando o mouse.
* Seleção de diferentes cores para o traço.
* Desenho de formula geometricas
* 
## 💻 Tecnologias e Ferramentas
* **Linguagem:** Java
* **Interface Gráfica:** Engine customizada (material didático)
